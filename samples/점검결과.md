# 점검 결과 (PLAN 작업 11)

- **점검일:** 2026-11-12
- **방법:** 개발 서버를 켠 상태에서 `node samples/점검.mjs` (샘플 5건 × 3회 반복, 실제 AI 호출)
- **정답표:** 초안 (숙련자 검토 전). 이 결과는 **참고용**이며, 숙련자가 정답표를 확정한 뒤 다시 돌려야 공식 결과가 됩니다.

## 이 점검의 한계

1. **샘플로 다듬은 결과입니다.** AI 지시문(작업 5.5)을 이 샘플 5건으로 시험하며 고쳤기 때문에, 100%는 낙관적인 숫자입니다. 새로운 자료(다른 표현, 다른 문서 양식)에서는 더 낮게 나올 수 있습니다.
2. **샘플은 한 사람(작성자)이 만든 가상 자료입니다.** 실제 등기부등본은 표기·양식이 훨씬 다양합니다. 마스킹한 실제 양식 자료로 한 번 더 확인하는 것을 권장합니다.
3. **정답표는 초안입니다.** 숙련자가 순위·판정을 검토하면 정답이 바뀔 수 있습니다.
4. **법적 순위 규칙(법정기일, 확정일자, 소액임차인 최우선변제)은 반영하지 않았습니다.** 숙련자 정답이 이 규칙을 따른다면 일치율이 낮아질 수 있습니다. (결과 화면에도 "반영하지 않은 규칙"으로 안내함)
5. **시간은 서버 처리 시간입니다.** 실제 Vercel에서는 처음 요청 때 시작 지연이 더 붙을 수 있어 배포 후 다시 재야 합니다.

## 다시 돌리는 방법

```
npm run dev          # 한 터미널에서 개발 서버 켜기
node samples/점검.mjs   # 다른 터미널에서 점검 실행 (통과하면 종료 코드 0)
```
