# samples — 가상 샘플 6건과 정답표

권리분석 에이전트의 점검(작업 11)에 쓰는 **가상 자료**입니다. 모든 이름·기관·주소는 지어낸 것이며 실제 개인정보나 대외비 자료가 없습니다. (PRD §7)

> **정답표는 초안입니다.** 권리분석 기준(`권리분석기준.md`, 교육자료 기준)과 PRD의 판정 세부 규칙을 그대로 적용해 만든 것이라, **숙련자(조세정리팀 담당자)가 검토·확정**한 뒤에 정확도 측정에 씁니다. 숙련자가 고친 내용은 `정답표.json`에 반영합니다.
>
> **2026-11-12 개정:** 정답표에 **말소기준권리, 처분(인수/소멸), 예상 배분순위, 공매 착수·반려 의견**이 추가되었고, 샘플 06(교육자료 기준 종합)을 새로 만들었습니다. 샘플 05는 "접수일자 없는 근저당"이 판정 보류의 원인이 되도록 바꿨습니다. (같은 날 접수한 담보채권은 교육자료 기준상 조세채권이 우선이라 더 이상 보류 원인이 아닙니다)

## 일치율 세는 법 (PLAN 성공 기준)

- **권리 항목 단위**로 셉니다. 분모는 정답표의 모든 권리 항목(말소·미등기로 제외된 항목 포함, 샘플 6건 합계 27건)입니다.
- 한 항목이 **일치**하려면 앱 결과의 `분류`(선순위/기준/후순위/미정/해당 없음/제외), `순위`(접수 순서 번호 또는 미정), `처분`(말소기준권리/인수/소멸), `예상 배분순위`(1~9순위)가 정답표와 같아야 합니다.
- 건마다 **말소기준권리**와 **공매 착수·반려 의견**도 정답표와 같아야 합니다.
- 앱이 정답표에 없는 항목을 더 만들어 냈거나 항목을 놓치면 **틀린 것**으로 셉니다. (분모는 그대로, 일치만 줄어듭니다)
- 5건 합계 **90% 이상**이면 통과입니다.
- 높음/보통/낮음/보류 **판정은 건별로 정답표와 같아야** 합니다. 5건 모두 일치가 목표입니다.
- 같은 샘플을 **3회 반복**해 순위와 판정이 항상 같아야 합니다.

## 규칙만 따로 하는 경계값 시험 (작업 8)

판정 계산은 샘플과 별도로 숫자만으로 시험합니다.

| 비율 | 기대 판정 |
|---|---|
| 49.99% | 높음 |
| 50.00% | 보통 |
| 80.00% | 보통 |
| 80.01% | 낮음 |

| 선순위 개수 | 기대 판정 |
|---|---|
| 0, 1건 | 높음 |
| 2, 3건 | 보통 |
| 4건 이상 | 낮음 |

그 밖에 권리 0건(판정하지 않음), 기준 권리 없음(판정 보류), 매각가 없음(개수 기준)도 확인합니다.
