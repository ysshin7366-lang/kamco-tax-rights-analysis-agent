# 캠코 조세정리업무 권리분석 에이전트

캠코 조세정리팀 팀원과 관심 있는 공사 직원이, 올린 자료로 **권리 순위와 배당 가능성**을 10분 안에 참고용으로 확인하는 웹 앱입니다.

> **결과는 항상 "참고용, 담당자 최종 확인 필요"입니다.** 이 앱은 의사결정을 돕는 보조 도구이며, 실제 공매 착수·반려는 담당자가 최종 판단합니다.
> 예시 자료는 모두 교육·실습용 **가상 자료**이며 실제 등기사항·체납정보와 무관합니다.

## 무엇을 하나요

1. **자료 올리기** — 등기사항전부증명서 등 자료 파일(.txt, 글자가 있는 .pdf, 한글 .hwpx, 엑셀 .xlsx)을 올립니다. 사건번호가 여러 개 들어 있으면 사건별로 자동으로 나눕니다.
2. **권리 정리** — AI가 자료에서 권리(근저당·가압류·압류·임차권 등)를 읽어 내고, 원문 근거 문장이 실제 자료에 있는지 코드로 검증합니다. 근거가 없는 항목은 결과에서 뺍니다.
3. **순위·판정** — AI가 아닌 **고정 규칙(코드)** 으로 말소기준권리, 인수/소멸, 예상 배분순위(1~9순위), 선순위 여부, 배당 가능성(높음·보통·낮음), 공매 착수/반려 검토 의견을 계산합니다. 같은 입력이면 항상 같은 결과가 나옵니다.
4. **보고서 내려받기** — 결과를 `양식/` 폴더의 **배분계산서·배분계산내역표 한글(.hwpx) 양식**에 채워 .zip으로 내려받습니다. 사건별 예상 매각금액, 강제징수비(사건당 10,000,000원), 추가 당해세 채권을 입력하면 배분금액까지 계산합니다.

## 배분순위 기준 (요약)

- 국세·지방세 압류와 근저당권: **법정기일과 근저당 설정일**을 비교해 빠른 쪽이 선순위 (같은 날이면 조세 우선)
- 국세·지방세 압류끼리: **압류일자** 순 (압류선착주의)
- 국세·지방세 압류는 가압류보다 항상 선순위
- 공과금(건강보험료 등)은 가압류와 동순위(채권액 비율로 안분)
- 당해세는 3순위로 담보·다른 조세보다 먼저 배분

## 기술

Next.js (App Router, TypeScript, Tailwind CSS) · OpenAI API(권리 읽기 1회 호출) · `unpdf`(PDF 글자 읽기) · `fflate`(hwpx/xlsx 처리) · Vercel 배포

## 실행 방법

```bash
npm install
```

프로젝트 폴더에 `.env.local` 파일을 만들고 OpenAI API 키를 넣습니다. (이 파일은 저장소에 올라가지 않습니다)

```
OPENAI_API_KEY=여기에_키_입력
```

```bash
npm run dev
```

브라우저에서 <http://localhost:3000> 을 엽니다.
